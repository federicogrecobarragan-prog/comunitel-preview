# Comunitel · propuesta de sitio (vista previa)

Vista previa de una **propuesta de diseño** para Comunitel S.A., preparada por el equipo de Federico Greco Barragán para revisión interna.
**No es el sitio oficial** (https://comunitel.com.ar/): los formularios no envían datos, el asistente responde en modo local y el
newsletter no está conectado a ningún proveedor.

Las imágenes nuevas son generadas con IA e ilustrativas. Logos y testimonios provienen de comunitel.com.ar y su uso está
sujeto a confirmación de Comunitel. Datos de mapa © colaboradores de OpenStreetMap (ODbL).

La propuesta V6 de sitio completo permanece en la raíz. La [one-page de Redes Subterráneas](https://federicogrecobarragan-prog.github.io/comunitel-preview/redes-subterraneas/) es una alternativa separada para revisión: no reemplaza la V6 ni el WordPress oficial. Su película y su 3D son conceptuales, no fichas técnicas; el formulario y WhatsApp están inactivos hasta que Comunitel apruebe los canales.

Este repositorio solo contiene los archivos públicos de las vistas previas; el proyecto vive en un repositorio privado.
